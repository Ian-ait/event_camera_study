# YOLO 从输入图片到输出检测框的过程

首先，把一张图片输入 YOLO 模型。

图片会先经过 CNN。CNN 会不断提取图片中的特征，并得到不同尺度的特征图。然后浅层特征图保留的细节会比较多，比如边缘、纹理和位置信息；深层特征图包含的语义信息更多，也是有效野更大，可以帮助模型判断图片中的物体是什么。

接着，模型会把不同尺度的特征图进行融合。这样既可以保留浅层的位置细节，也可以利用深层的语义信息。

然后，检测头会在不同尺度的特征图上进行预测。特征图中的每个 Grid 都可以理解为一个预测位置。模型会在这些位置上预测：

- 目标的边界框坐标
- 目标的类别
- 目标的置信度

不同尺度的特征图负责检测不同大小的目标。例如：

- $80\times80$ 的特征图主要检测小目标
- $40\times40$ 的特征图主要检测中等目标
- $20\times20$ 的特征图主要检测大目标

然后因为同一个目标附近的多个 Grid 都可能产生预测，所以一开始会得到很多重复的候选框。

模型会先删除置信度太低的框，然后使用 NMS 删除高度重叠的重复框，保留置信度更高的框。

最后，YOLO 输出目标的类别、置信度和边界框坐标。

整个过程可以总结为：

图片输入  
→ CNN 提取不同层次的特征  
→ 融合多尺度特征图  
→ 检测头产生候选框  
→ 过滤低置信度框  
→ NMS 删除重复框  
→ 输出最终检测结果
