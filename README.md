### 2026-08-04: Day 4-卷积神经网络

- 完成卷积层，填充与步幅，多输入与多输出通道，池化层的代码实现
- 完成卷积神经网络输出尺寸的计算并用pytorch验证
- 跑通leNet，并对比在MLP上的正确率
- **问题回答：**卷积核本质是一堆可学习的滤波器，在网络训练中不断更新自己内部的权重，然后卷积核主要是去学习图片的基础局部特征，通道数越多，卷积核能学习不同的局部特征，从而识别更复杂的特征。而特征图越小是因为卷积，池化在提取过程中做了下采样，压缩掉不重要的特征，减小计算负担，因为通道越多，计算量便越大，所需要的计算资源也就越多，所以减小特征图
